🧮 Calculadora



Uma calculadora simples desenvolvida com HTML, CSS e JavaScript.



Este projeto foi desenvolvido para praticar conceitos básicos de desenvolvimento web.



🚀 Funcionalidades

➕ Soma

➖ Subtração

✖️ Multiplicação

➗ Divisão

🔢 Números decimais

🧹 Limpar cálculo

⌫ Apagar último número

⚠️ Tratamento de operações inválidas

🛠️ Tecnologias utilizadas

HTML5

CSS3

JavaScript

📂 Estrutura do projeto

Calculadora/

├── index.html

├── style.css

├── script.js

└── README.md

▶️ Como executar

Baixe ou clone este repositório.

Abra a pasta do projeto.

Abra o arquivo index.html.

A calculadora será aberta no navegador.
